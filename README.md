## 🇺🇸 PoliDebater — AI-Powered Political Debate Trainer

PoliDebater is a web app that lets users debate political topics with an LLM in a structured, educational format. Built for the Congressional App Challenge, it combines civic learning with responsible AI to help students strengthen argumentation, critical thinking, and media literacy.

### 🎯 Purpose

Online political discussion is often unproductive and unstructured. PoliDebater gives students a space to practice clear, evidence-based argumentation through formats like Claim-Warrant-Impact and the Toulmin model. After each debate, the AI provides targeted feedback and suggestions for improvement. Users can also generate permanent sharable links to review or submit their debates.

### 🧠 How It Works

Choose a topic and debate structure

Debate the LLM over multiple rounds

Receive feedback on logic, clarity, and reasoning

Optionally generate a sharable link to the full debate

The goal is to make structured political discussion accessible and educational.

### 🏗️ Tech Stack

Next.js + React + TypeScript

Tailwind CSS (UI)

Zustand (state management)

Redis (stores permanent debate links)

OpenAI API + Next.js Route Handlers (LLM generation)

Git/GitHub for version control

### ✅ Features

Structured debate formats

Adjustable difficulty and round settings

AI feedback at the end of each debate

Sharable debate links

Clean, responsive UI
